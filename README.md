# Arise Website

Official landing page and Privacy Policy site for **Arise — Alarm Clock for Android**.

## Stack

- Vite
- React
- Plain CSS
- No UI framework dependency

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Vercel

Import this repository in Vercel and use the default Vite settings:

- Build command: `npm run build`
- Output directory: `dist`

## Important links to update

In `src/config.js`, update these values when needed:

- `githubUrl`
- `releasesUrl`
- `googlePlayUrl`
- `supportEmail`
